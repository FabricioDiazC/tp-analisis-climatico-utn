# TP – Análisis de Datos Climáticos Globales
## Escenario Elegido
**Escenario A – Análisis de Datos Climáticos**

## Dataset Utilizado
- **Fuente:** GISTEMP / GCAG vía DataHub.io
- **URL:** https://datahub.io/core/global-temp
- **Formato:** CSV
- **Descripción:** Anomalías de temperatura global registradas mensual y anualmente.

## Estructura del Repositorio
tp-analisis-climatico-utn/
├── datos/          → Dataset CSV original
├── scripts/        → Código Python de análisis
├── resultados/     → Gráficos y CSV exportados
├── README.md       → Documentación del proyecto
└── .gitignore      → Exclusiones de archivos sensibles/temporales

## Instrucciones para Ejecutar el Script
1. Abrí Google Colab: https://colab.research.google.com
2. Cloná el repositorio usando las celdas del notebook.
3. Ejecutá `scripts/analisis_climatico.py`.
4. Los resultados se guardarán automáticamente en `/resultados`.
